배포 여정

내 컴퓨터에서만 열리던 화면을, 가족 누구나 인터넷 주소로 열어보는 화면으로 바꾸는 과정입니다. 데이터를 보관하는 Firebase와, 화면을 인터넷에 올려주는 GitHub, 두 개의 무료 서비스를 연결하면 됩니다. 순서대로 따라 하면 한 시간 안에 끝납니다.

1부 Firebase 준비 데이터를 저장할 공간 만들기 2부 GitHub에 올리기 화면을 인터넷 주소로 만들기 3부 확인하고 나누기 주소를 열어보고 가족에게 보내기
1부

Firebase 준비

Firebase는 구글이 만든 무료 데이터 보관함입니다. 시후가 입력한 계획표 기록이 실제로 저장되는 곳이 여기입니다. 5단계로 끝납니다.

프로젝트 만들기

console.firebase.google.com 에 구글 계정으로 로그인한 뒤, 프로젝트 추가를 누르고 이름을 정합니다. 애널리틱스는 꺼도 됩니다.

console.firebase.google.com
프로젝트 이름sihu-study-plan
프로젝트 만들기 →

Firestore Database 만들기

왼쪽 메뉴 빌드 → Firestore Database → 데이터베이스 만들기. 위치는 asia-northeast3 (서울)을 고릅니다.

빌드 › Firestore Database
위치asia-northeast3 (서울)
사용 설정

보안 규칙(Rules) 붙여넣기

만들어진 화면 위쪽의 규칙 탭을 클릭합니다. 안에 이미 적혀 있는 코드를 전부 지우고, 아래 코드를 그대로 붙여넣은 뒤 게시를 누릅니다.

// 로그인한 사람만 자기 가족 공간을 읽고 쓸 수 있다 rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /families/{familyId}/{document=**} { allow read, write: if request.auth != null; } } }
이게 무슨 뜻인가요 기본값은 "누구나 30일 동안 마음대로" 접근할 수 있는 상태입니다. 이 규칙으로 바꾸면 "로그인한 사람만" 접근할 수 있게 됩니다. 실제로 어느 가족 데이터인지는 다음 단계에서 자동으로 만들어지는 무작위 코드가 구분해줍니다.

로그인 방법 켜기 — 익명(Anonymous)

왼쪽 메뉴 빌드 → Authentication → 시작하기 → Sign-in method 탭 → 목록에서 익명(Anonymous)을 찾아 클릭 → 사용 설정 스위치를 켜고 저장.

Authentication › Sign-in method
익명사용
자동 정리 사용 설정
로그인 화면이 안 뜨는 이유 이걸 켜두면 시후나 부모님이 화면을 열 때 아이디·비밀번호 없이 앱이 알아서 조용히 로그인합니다. "자동 정리"도 함께 체크해두면 좋습니다 — 30일 넘게 안 쓰인 로그인 기록을 구글이 알아서 정리해주고, 시후의 실제 기록에는 전혀 영향이 없습니다.

웹 앱 등록하고 설정 값 복사

⚙ 프로젝트 설정 → 아래로 스크롤 → 내 앱 → 웹(</>) 아이콘 클릭 → 이름 입력 → Firebase 호스팅 체크박스는 켜지 않기 → 앱 등록.

프로젝트 설정 › 내 앱
앱 닉네임시후 계획표

앱 등록

등록하면 이런 코드가 화면에 나타납니다. { } 안의 내용 전체가 필요한 값입니다.

const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "내프로젝트.firebaseapp.com", projectId: "내프로젝트", storageBucket: "내프로젝트.appspot.com", messagingSenderId: "...", appId: "1:...:web:..." };
파일에 넣기 이 코드를 통째로 복사해서 프로젝트의 docs/firebase-config.js 파일 안, 이미 있는 firebaseConfig 값 자리에 그대로 바꿔 넣으세요. apiKey는 비밀번호가 아니라 원래 공개되는 값이라 안심하고 저장소에 올려도 됩니다 — 실제 보안은 3단계의 규칙과 3부에서 만들 무작위 가족 코드가 담당합니다.
2부

GitHub에 올리기

GitHub는 코드를 보관하고, 그 코드를 인터넷 주소로 열어볼 수 있게 해주는 무료 서비스입니다(이 기능 이름이 GitHub Pages입니다). 4단계로 끝납니다.

저장소(repository) 만들기

github.com/new 에서 이름을 정하고 만듭니다.

github.com/new
Repository namesihu-study-plan
Public Private
Add a README file Add .gitignore
Create repository
두 가지만 지키면 끝 Public을 선택하세요 — 무료 계정은 Private으로 인터넷 공개(Pages)를 켤 수 없습니다. 코드만 공개되고, 시후의 실제 기록은 Firebase에만 있어 괜찮습니다. 그리고 아래 세 체크박스는 전부 꺼둔 채로 두세요 — 이미 완성된 코드가 있어서, 체크하면 파일이 충돌합니다.

개인 액세스 토큰 만들기

2021년부터 GitHub는 비밀번호로 코드를 올리는 걸 막았습니다. 대신 임시 열쇠(토큰)를 한 번 만들어야 합니다.
프로필 사진 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).

컴퓨터의 코드를 올리기

터미널을 열고, 프로젝트 폴더에서 아래 세 줄을 순서대로 입력합니다. (저장소를 처음 만드는 경우의 예시입니다)

# 저장소 주소는 방금 만든 페이지에서 그대로 복사
$ git remote add origin https://github.com/계정명/저장소명.git
$ git branch -M main
$ git push -u origin main

Username for 'https://github.com': 계정명
Password for '...': (복사해둔 토큰을 붙여넣기 — 화면엔 안 보임)

✓ * [new branch]      main -> main
비밀번호 칸에 토큰을 Username에는 GitHub 계정명을, Password에는 방금 만든 토큰(ghp_...)을 붙여넣으세요. 붙여넣어도 화면에 글자가 하나도 안 보이는 게 정상입니다 — 원래 그렇게 만들어져 있습니다. 마지막 줄에 [new branch] main -> main이 보이면 성공입니다.

GitHub Pages 켜기

저장소 페이지 → Settings → Pages → Source를 Deploy from a branch로 → Branch는 main / /docs 선택 → Save.

Settings › Pages
SourceDeploy from a branch
Branchmain/docs Save
폴더 선택이 핵심 / (root)이 아니라 반드시 /docs를 골라야 합니다 — 가족이 함께 보는 화면 코드가 그 폴더 안에 있습니다. 저장 직후엔 아직 준비 중이고, 보통 1~5분 뒤에 실제 주소가 열립니다.

확인하고 나누기

여기부터는 클릭 몇 번이면 끝납니다.

배포된 주소 열어보기

주소 형태는 https://계정명.github.io/저장소명/ 입니다. 열었을 때 "가족 공간이 만들어졌습니다" 화면이 뜨면 성공입니다.

가족과 링크 나누기

온보딩 화면(또는 오른쪽 위 🔗 공유 버튼)에 있는 링크 복사를 눌러, 그 링크를 나머지 가족에게 보내주세요. 그 링크를 연 사람이 같은 계획표를 함께 봅니다.

꼭 기억할 것 아무 링크로나 열면 서로 다른 가족 공간이 만들어집니다. 한 사람이 먼저 열어서 만든 링크를, 상대방이 받아서 열어야 같은 기록을 공유합니다.

막혔을 때

규칙(Rules) 탭에 원래 있던 코드는 어떻게 하나요?

전체를 지우고(Cmd+A 후 삭제) 그 자리에 1부 3단계의 코드를 붙여넣으면 됩니다. 붙여넣기만 하고 게시를 안 누르면 적용되지 않습니다.

익명(Anonymous)을 목록에서 못 찾겠어요

목록이 길면 아래로 스크롤하거나, 위쪽의 새 제공업체 추가 버튼을 눌러 나오는 팝업에서 찾아야 할 수도 있습니다. 화면 버전에 따라 위치가 조금 다릅니다.

터미널에서 아이디/비밀번호를 안 물어보고 그냥 됐어요

정상입니다. macOS가 별도의 작은 팝업 창으로 한 번만 물어보고 그다음부터는 기억해두는 경우가 많습니다. 마지막 줄에 [new branch] main -> main이 보이면 성공한 것입니다.

Pages를 저장했는데 주소가 안 열려요

처음 저장한 직후엔 사이트를 만드는 데 1~5분 걸립니다. 잠시 후 Settings → Pages 화면을 새로고침하면 초록색 체크와 함께 정확한 주소가 나타납니다.

가족 두 명이 서로 다른 화면을 봐요

둘이 각자 다른 링크(또는 처음 그냥 주소만)로 열면 서로 다른 가족 공간이 자동으로 만들어집니다. 한 명이 먼저 열어서 나온 링크를, 반드시 상대방이 받아서 열어야 같은 기록을 보게 됩니다. 오른쪽 위 🔗 공유 버튼에서 지금 링크를 다시 확인하거나, 다른 코드로 전환할 수 있습니다.

공개(Public) 저장소인데 시후의 기록이 남에게 보이지 않나요?

안 보입니다. 저장소에는 프로그램 코드만 있고, 시후가 실제로 쓴 계획·기록은 전부 Firebase 안에 저장됩니다. 그 데이터는 무작위 가족 코드를 아는 사람만 볼 수 있습니다.

여기까지 마치면 인터넷 어디서나, 가족 누구나 같은 계획표를 보고 쓸 수 있습니다. 나중에 코드를 고치면 git push를 한 번 더 실행하는 것만으로 반영됩니다.
